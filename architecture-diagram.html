Dual-Chain Offline Payment System: Stellar (Ed25519/SHA-256) + EVM (Secp256k1/Keccak-256) — Merkle-Batched Bilateral Settlement

Dual-Chain Cryptography

  • EVM: ethers.js v6 · Secp256k1 · EIP-191 personal sign · EIP-712 typed data
  • Stellar: @stellar/stellar-sdk · Ed25519 · SHA-256 · HMAC signatures
  • Merkle Tree: Keccak-256 (EVM) / SHA-256 (Stellar) · buildRealEvmMerkleTree()
  • Go WASM Core: High-performance crypto via WebAssembly runtime
  • WebCrypto Fallback: Pure JS SHA-256 + ECDSA P-256 for untrusted contexts
  • Bilateral Signing: Payer signs payload → Payee countersigns receipt

Offline Transfer Mechanisms

  • NFC (Web NFC NDEFReader): Tap-to-pay, navigator.vibrate() haptics, text/plain JSON record
  • BLE (Web Bluetooth API): 4-5m proximity, GATT server handshake, UUID 0000ffe0/ffe1
  • QR Code: High-contrast B/W, 480px width, qrcode library, errorCorrectionLevel=M
  • Simulator: Dual-device cross-device emulated transfer for demo/testing
  • No internet required between payer and merchant at any point
  • Both devices maintain full transaction history in localStorage

  • Base Sepolia (#84532): L2 testnet, same USDC contract, lower gas
